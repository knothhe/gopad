启动台新增右键整理、拖动排序和拖入分区，隐藏应用后可撤销。可选显示最近使用，或将自定义分区呈现为文件夹；文件夹与分区共用成员。

搜索默认覆盖全部未隐藏应用，优先显示名称相关结果，并支持调整搜索范围与排序。新增分区建议预览、自定义全局快捷键、登录启动和交互偏好，包括页码记忆、循环翻页、空白处关闭、Esc 清空搜索及 Tab 导航。

修复 macOS 菜单栏导致启动台下移、底部超出屏幕的问题。改善多显示器壁纸切换、重复打开性能，以及管理窗口和启动台同时整理应用时的设置合并。

升级时自动迁移应用标识，保留收藏、隐藏、排序和分区成员；同一应用的多个安装副本仍分别显示。最近使用默认关闭，开启后仅记录通过 gopad 成功启动的应用。

The launcher now supports context menus, drag ordering, section drops, and undo after hiding an app. Optional recent apps, section folders, and metadata-based section suggestions provide more ways to organize your apps.

Search defaults to all visible apps and ranks name matches first. Settings now include search scope and ranking, a custom global shortcut, launch at login, page memory, page looping, background dismissal, Escape behavior, and Tab navigation.

This release fixes the macOS menu bar shifting the launcher offscreen and improves display-specific wallpapers, reopening performance, and concurrent preference edits. Application identities migrate while preserving organization. Recent history is off by default and records only successful launches through gopad when enabled.
