本版包含 v0.1.5 的启动台改进。v0.1.5 的发布检查未通过，未生成公开安装包；本版修正了前端测试对固定等待时间的依赖。

启动台新增右键整理、拖动排序、拖入分区和隐藏撤销。可选显示最近使用，或将自定义分区显示为文件夹；支持预览并添加基于应用类别的分区建议。

搜索默认覆盖全部未隐藏应用，并优先显示名称相关结果。设置中可调整搜索范围与排序、自定义全局快捷键、登录启动、页码记忆、循环翻页、空白处关闭、Esc 行为及 Tab 导航。

修复 macOS 菜单栏导致启动台下移、底部超出屏幕的问题，改善多显示器壁纸切换、重复打开性能和并发设置保存。升级时自动迁移应用标识并保留已有整理结果。最近使用默认关闭，开启后仅记录通过 gopad 成功启动的应用。

This release includes the launcher improvements prepared for v0.1.5, whose release checks failed before any public installation package was produced. It fixes a timing-dependent frontend test.

New features include app context menus, drag ordering, section drops, hide undo, optional recent apps, section folders, and category suggestions. Search defaults to all visible apps and ranks name matches first. Settings include search scope and ranking, a custom global shortcut, launch at login, page memory, looping, background dismissal, Escape behavior, and Tab navigation.

The macOS launcher no longer shifts below the menu bar and offscreen. Display-specific wallpapers, reopening performance, and concurrent preference saves are improved. Application identities migrate while preserving organization; recent history remains opt-in.
